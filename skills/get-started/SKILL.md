# IRBANK Connect を使い始める

1. IRBANK Connect に接続済みか確認してください。未接続なら、利用中のクライアントのプラグイン画面で IRBANK Connect を有効にし、MCPの認証操作からIRBANK アカウントでサインインして「許可する」を押すよう案内してください。
2. 「本人確認が必要です」と表示された場合は、https://app.irbank.net/mcp-api で氏名・住所を登録してから再接続するよう案内してください。
3. 接続できたら、次の質問例を案内してください。
   - 「トヨタ自動車の過去10年の売上高・営業利益・純利益の推移を教えて」
   - 「配当利回り3%以上でPER15倍以下の銘柄を抽出して」
   - 「ソニーグループのセグメント別営業利益を見せて」

## ツールの使い方

- 銘柄名から識別子を得るには、`screen_securities` の `name` を使ってください。返された `edinet_code` / `security_code` を他のツールに渡してください。
- 内部証券コードは5文字です。ツールが返すコードを使ってください。表示用コードとの対応例は `7203` と `72030` です。
- 金額や比率の単位は、レスポンスの `fields[].unit` に従ってください。`million_jpy` は百万円です。換算した場合は換算後の単位を明記してください。
- 株価の時系列比較には、分割調整後終値の `adj_close` を使ってください。
- すべてのツールは読み取り専用です。売買・発注・ユーザーデータの変更はできません。投資助言は行いません。
- 出典はレスポンスの `attribution` に従い、IRBANKによる加工も明記してください。取得できない値や本文、URLは推測で補わないでください。

## 対象外の依頼への応答

- 株式の購入や注文を求められた場合は、読み取り専用のため実行できないことを先に伝え、ツールは呼び出さないでください。注文済みとは回答しないでください。
- 「今すぐ買うべき銘柄を1つ」など、購入銘柄を決める投資助言は対象外です。買い候補を選ぶためにツールを使わず、投資助言は提供しないことを伝えてください。代わりに、利用者が指定した条件に基づく事実情報の比較を案内してください。
- Apple（AAPL）など日本株以外の財務データは、このMCPの対象外です。ツールを呼び出さずに対象外と伝え、数値や出典を推測で補わないでください。
